# type-contracts — decisions

What was measured and decided, why, and on what evidence. Never cleared. When a
decision is reversed, mark the old entry `Superseded by <date>.` and add the new
one below it. A re-measure that disagrees with a count gets a dated line under
the entry; the old number stays.

Where this file disagrees with the summary in SKILL.md, this file wins.

### 2026-09-21 — adopted `noUncheckedIndexedAccess` and `noImplicitReturns`
Measured with `npx tsc -p tsconfig.app.json --noEmit --<flag>`: 65 errors for
indexed access across about 22 files, 0 for implicit returns. All 65 fixed by
narrowing; no `!` added. One was a live crash path: the rainfall chart indexed
`months[monthIndex(row.date)]` with no guard on the CSV date format.

### 2026-09-21 — adopted typed lint, `no-unsafe-*` only
The full `recommendedTypeCheckedOnly` set raised 49 problems outside
`components/ui/` and 10 inside it. Adopted the five `no-unsafe-*` rules plus
`no-unnecessary-type-assertion`, scoped to `src/` with `components/ui/` ignored
because that folder is generated by shadcn. About 22 of the unsafe hits came
from two hand-rolled `JSON.parse` loaders. After the change: 0 problems.

### 2026-09-21 — declined `no-floating-promises` and `no-misused-promises`
13 sites, all event handlers and fire-and-forget copies. The fix is `void` at
each one. They are about promise handling, not types, and CI blocks the deploy
on lint errors, so the cost was judged higher than the value.

### 2026-09-21 — declined `exactOptionalPropertyTypes`
14 errors, mostly optional props passed through shadcn and React prop types.

### 2026-09-21 — declined `noPropertyAccessFromIndexSignature`
8 errors, all `fields.title` / `el.dataset.reveal` style accesses that would
become `fields["title"]`. Style only; no bug class caught.

### 2026-09-21 — `readStoredObject()` lives in `src/lib/browser.ts`
It replaced three separate `JSON.parse` + try/catch loaders (font size, Browser
Mockup, Code Annotator). `font-size.ts` runs before first paint and
`browser.ts` imports `sonner`, so the import looked like a cost. It is not:
`main.tsx` already mounts the toaster, and the build puts `sonner` in the main
`index-*.js` chunk either way (checked by grepping `dist/assets/` for
`data-sonner-toaster`).

### 2026-09-21 — CSV rows need an ISO date, month-checked
`isIsoDate` (`^\d{4}-(0[1-9]|1[0-2])-\d{2}$`) replaced `typeof date ===
"string"` for temperature, wind and rain rows. Checked against the real files
first: 0 rows rejected in each, and the page still reports 3,684 days. The day
is deliberately not range-checked; see Known gaps in SKILL.md.

### 2026-09-21 — timeline `year` is derived from `dateRange`
The stored `year` field had to equal the start year of `dateRange` by hand, a
rule `CLAUDE.md` carried as a warning. A script confirmed the first four-digit
year in `dateRange` equalled the stored `year` for all 8 positions, then the
field was deleted from `professionalJourney.json` and the rule from
`CLAUDE.md`.

### 2026-09-21 — casts are allowed for our own data coming back through a library
Recharts types tooltip and bar payloads as `any`. The three sites cast to a
shape naming only the fields read, with a comment saying why. Not allowed for
storage, files or the network, where the data is not ours.
