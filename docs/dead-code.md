# Dead-code baseline

Accepted findings from `npm run knip` and the dead-code skill's
`audit.ts`. Read this before an audit so known exceptions are not
re-reported as new.

## Handled in `knip.json`

- **`src/maintenance.tsx` is an entry.** The `maintenanceMode()` plugin in
  `vite.config.ts` swaps it in for `main.tsx` when `siteConfig.online` is
  `false`, so knip cannot find it from `index.html`. Without the entry it
  and `pages/maintenance-page.tsx` show as unused files, and
  `StatusBar` in `components/editorial.tsx` as an unused export.
- **Exports in `src/components/ui/` are ignored.** That directory is
  generated by `npx shadcn add`; unused subcomponents and variant helpers
  (`CardFooter`, `SheetClose`, `buttonVariants`, …) come back on the next
  add, so trimming them is churn. Unused *files* there are still reported.

## Known `audit.ts` false positives

- **Page components** (`AboutPage`, `SqlPlaygroundPage`, …) are flagged as
  unused exports. `App.tsx` loads them through `lazy(() => import(...))`,
  which the regex scan does not follow. knip does.
- **`SqlSchema`** in `sql-playground/sql-editor.tsx` is used in-file as the
  editor's prop type.
